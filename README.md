Meu Primeiro Site

Sobre o projeto

Este foi um dos meus primeiros projetos de desenvolvimento web, criado durante meus estudos em Desenvolvimento de Sistemas. O objetivo foi praticar os conceitos básicos de HTML e compreender a estrutura de uma página web.

Funcionalidades

- Estrutura básica de uma página HTML
- Organização de conteúdo
- Prática de marcação com HTML
- 
Tecnologias utilizadas

- HTML5

Como executar

1. Clone este repositório:

```bash
git clone https://github.com/SEU-USUARIO/meu-primeiro-site.git
```

2. Abra a pasta do projeto.

3. Execute o arquivo `index.html` em qualquer navegador.
